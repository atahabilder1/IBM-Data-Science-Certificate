# IBM Data Science Capstone Project

## SpaceX Falcon 9 First Stage Landing Prediction

This project analyzes SpaceX launch data to predict successful first stage landings.

### Project Structure
- Data Collection via SpaceX API
- Web Scraping for launch records
- Exploratory Data Analysis with SQL
- Data Visualization
- Interactive Maps with Folium
- Machine Learning Prediction Models

### Files
- `jupyter-labs-spacex-data-collection-api.ipynb` - API data collection
- `jupyter-labs-webscraping.ipynb` - Web scraping implementation
- `jupyter-labs-eda-dataviz-v2.ipynb` - EDA visualizations
- `jupyter-labs-eda-sql-coursera_sqllite.ipynb` - SQL analysis
- `lab-jupyter-launch-site-location-v2.ipynb` - Folium maps
- `SpaceX-Machine-Learning-Prediction-Part-5-v1.ipynb` - ML models
